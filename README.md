# Lessgooo — DevOps from zero to hero

A responsive static learning landing page made with plain HTML, CSS, and JavaScript. No framework, build step, or package installation required.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in your browser.

For a local development server, from this directory run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive layout, theme, and animations
- `script.js` — interactive roadmap, stage completion toggles, command selector, copy button, and mobile navigation

## Notes

- The demo command panel explains safe, read-only Linux commands. It does not execute commands in your terminal.
- The learning stages and projects are starter guidance, not a certification or guarantee of job readiness.
- Google Fonts are loaded from an external service; the site still works with fallback fonts if they are unavailable.
